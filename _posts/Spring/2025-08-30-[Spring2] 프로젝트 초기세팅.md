#### 1. 왜 IntelliJ를 많이 추천할까?
자바 개발 이야기를 조금만 들어봐도 "IntelliJ 써라"라는 말을 정말 많이 듣는다.  
다른 언어에서는 Visual Studio Code(이하 VS Code)도 충분히 좋은 선택이지만, 자바에서는 IntelliJ에 대한 추천 빈도가 압도적으로 높다.  

그 이유는 다음과 같다.  
- 강력한 코드 지원: 리팩토링, 코드 자동완성, 에러 감지 기능이 자바 생태계에 최적화되어 있다.  
- Spring Boot 친화적: 스프링 관련 플러그인, 런/디버깅 지원이 VS Code보다 훨씬 매끄럽다.  
- 프로젝트 관리 편의성: Gradle, Maven 설정과 연동이 쉬워서 초기에 삽질을 줄일 수 있다.  

특히, 개발 생산성을 크게 올려주는 단축키가 많다.  
- `Shift + Shift` : 전체 파일/클래스/설정 검색  
- `Ctrl + Shift + A` : 액션/설정 검색  
- `Ctrl + B` : 선언부로 이동 (메소드/클래스 추적)  
- `Ctrl + Alt + L` : 코드 자동 정렬(포매팅)  
- `Ctrl + Shift + F10` : 현재 파일 실행  
- `Alt + Insert` : 생성자, Getter/Setter, toString 등 자동 생성  

이 단축키들만 익혀도 개발 속도가 훨씬 빨라진다.  

---

#### 2. 무료 vs 유료 버전
IntelliJ는 크게 Community(무료)와 Ultimate(유료) 버전으로 나뉜다.  

- Community 버전  
  - 순수 자바, Kotlin, Gradle/Maven 프로젝트 지원  
  - 오픈소스/학습용으로 충분히 사용 가능  

- Ultimate 버전  
  - 스프링, JPA, 데이터베이스 연동 등 엔터프라이즈 개발 기능 지원  
  - 실무에서 현업 개발자들이 주로 사용하는 버전  

현업에서는 Ultimate을 많이 쓰지만, 학습 단계에서는 Community 버전으로도 충분하다.  
무료 버전으로라도 익숙해지면, 이후 현업에서 Ultimate을 접했을 때도 쉽게 적응할 수 있다.  

---

#### 3. 스프링 부트를 선택하는 이유
스프링은 자바 진영에서 가장 많이 쓰이는 프레임워크다.  
하지만 순수 스프링만으로 프로젝트를 시작하려면 설정이 너무 복잡하다.  

- 수많은 XML/설정 파일 필요  
- 의존성 라이브러리 직접 추가 및 관리  
- 실행 환경 구성에 시간 소모  

이런 복잡성을 줄여주는 것이 Spring Boot이다.  
스프링 부트는 "빠르게 실행 가능한 스프링 애플리케이션"을 만들 수 있도록, 기본 설정과 의존성을 미리 패키징해둔 프로젝트 스타터 역할을 한다.  

---

#### 4. Gradle vs Maven
스프링 프로젝트를 만들다 보면 가장 먼저 마주치는 질문이 있다.  
“빌드 도구를 뭘로 할까? Gradle? Maven?”  

둘 다 프로젝트 관리/빌드/의존성 관리 도구이지만 차이가 있다.  

- Maven  
  - XML 기반 설정 (정형화되어 있으나 장황하다)  
  - 보수적이고 안정적, 문서 자료가 많음  
  - 큰 기업이나 레거시 프로젝트에서 많이 쓰임  

- Gradle  
  - Groovy/Kotlin DSL 기반 설정 (간결하고 유연하다)  
  - 빌드 속도가 빠르고 확장성이 좋음  
  - 최신 트렌드의 프로젝트에서 선호됨  

요약하면,  
- 학습 목적과 최신 프로젝트에는 Gradle이 적합하다.  
- 기업 레거시 시스템 대응에는 Maven도 알아두는 것이 좋다.  

---

#### 5. 초기 세팅 요약
스프링 부트를 시작하기 위한 최소 세팅은 다음과 같다.  

1. 개발 환경  
   - IDE: IntelliJ (권장), VS Code(확장팩 필요)  
   - JDK: Java 17 이상 권장 (LTS 버전 사용)  

2. 프로젝트 생성  
   - [Spring Initializr](https://start.spring.io/)에서 프로젝트 뼈대 생성  
   - 빌드 도구 선택: Gradle or Maven  
   - 주요 의존성 추가: Spring Web, Spring Boot DevTools, Lombok, JPA 등  

3. 실행  
   - IntelliJ에서 `main()` 실행 → 내장 톰캣 서버가 구동 → `http://localhost:8080` 접속  

---

#### 6. 마무리
정리하면,  
- 자바 개발은 IntelliJ를 쓰는 것이 가장 효율적이다.  
- 현업에서는 Ultimate을 많이 쓰지만, 학습 단계에서는 Community 버전으로 충분하다.  
- 스프링은 스프링 부트로 시작하는 것이 사실상 표준이다.  
- 빌드 도구는 Gradle과 Maven이 있는데, 최신 트렌드에는 Gradle이 더 적합하다.
